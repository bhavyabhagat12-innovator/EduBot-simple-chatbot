# EduBot 🎓

A simple rule-based chatbot that answers common engineering student questions about CGPA, attendance, study tips, exams, backlogs, Python, projects and stress.

Built as a PPS mini project for B.Tech AI & Data Science.

## Features
- Keyword-based question matching
- Covers CGPA, attendance rules, study and exam tips, and more
- Random programming jokes
- Web interface built with Streamlit
- Also runs in the terminal

## Live Demo
[Try EduBot here] https://edubot-simple-chatbot-bbi.streamlit.app/

## Tech Stack
- Python
- Streamlit

## How to Run Locally

1. Clone the repo
```bash
   git clone https://github.com/bhavyabhagat12-innovator/EduBot.git
   cd EduBot
```
2. Install dependencies
```bash
   pip install -r requirements.txt
```
3. Run the web app
```bash
   streamlit run app.py
```
   Or run in the terminal:
```bash
   python chatbot.py
```
